# Alex Security Labs

Hands-on cybersecurity, Linux, networking and security engineering labs built in my personal home environment.

## Current Lab

- Arch Linux
- Linux Zen
- KDE Plasma
- Tailscale
- OpenSSH
- nftables
- Wireshark / tshark / dumpcap
- Nmap
- Python

## Projects

### 01 - Secure Remote Linux Access

Securely administering an Arch Linux endpoint using:
- Tailscale private networking
- OpenSSH
- ED25519 public-key authentication
- nftables network filtering
- Nmap validation
- Wireshark traffic analysis

### 02 - Network Visibility

Practical analysis of:
- ARP
- DNS
- TCP
- SSH
- Encrypted network traffic

### 03 - PCAP Explainer

A Python desktop application (`tkinter` + `dumpcap` + `tshark`) that translates raw packet captures into human-readable security telemetry:
- Live packet capture and protocol breakdown
- DNS query/response and IPv4/IPv6 mapping
- TCP stream reconstitution and 3-way handshake validation
- Evidence-based security observations (encrypted vs. plaintext HTTP)

## Goal

Develop practical skills in Linux administration, networking, security telemetry, troubleshooting and detection-oriented security engineering.
